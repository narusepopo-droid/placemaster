핵심기능

매장 리뷰 수집의 모든 것을 자동화합니다

🧾

영수증 자동 전송

포스에서 결제하면 영수증이 자동으로 캡처되어 손님 폰으로 전송됩니다. 영수증 찾아드릴 필요 없어요.

✍️

리뷰 문구 자동 생성

매장에 맞는 리뷰 문구가 자동으로 생성되어 클립보드에 복사됩니다. 손님은 붙여넣기만 하면 끝.

📱

앱 설치 불필요

손님은 앱 설치 없이 QR만 찍으면 됩니다. 웹 브라우저에서 바로 진행되어 진입 장벽이 없어요.

👥

고객 DB 자동 적립

참여한 손님의 휴대폰 번호가 자동으로 DB에 쌓입니다. 나중에 홍보 문자 발송에 활용하세요.

📊

실시간 대시보드

오늘 참여 수, 리뷰 완료 수, 단계별 이탈률을 실시간으로 확인하세요. 에이전트 상태도 모니터링.

💬

문자 마케팅

영수증 리뷰에 참여한 고객들에게 문자 홍보, 쿠폰 발송이 가능합니다. 자동으로 쌓인 고객 DB를 활용하세요.
